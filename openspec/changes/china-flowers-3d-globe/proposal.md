## Why

中国幅员辽阔、气候多样，孕育了数千种特色花卉，但目前缺乏一个直观、可交互的方式让用户探索不同地域、不同季节的花卉分布。本应用通过3D地球可视化，将花卉地理分布与季节信息结合，让用户以沉浸式体验了解中国花卉文化。

## What Changes

- 新增基于 WebGL 的3D地球交互界面，用户可旋转、缩放查看中国各省份
- 新增花卉数据集，包含花名、图片、描述、花期、分布省份等结构化信息（**数据来自真实来源，非 mock**）
- 新增数据采集脚本：整合省市花官方数据 + GBIF API 查询，生成应用所需 JSON 数据集
- 新增地图区域标注，在3D地球上以热点/标记展示各地花卉分布
- 新增季节筛选面板（春/夏/秋/冬），动态过滤当季花卉并更新地球显示
- 新增花卉详情弹窗，展示单种花的完整信息（形态、文化意义、观赏地点）

## Capabilities

### New Capabilities

- `globe-viewer`: 3D地球渲染与交互能力 —— 地球旋转、省份高亮、视角控制
- `flower-catalog`: 花卉数据目录 —— 花卉条目的数据结构、存储与检索
- `regional-mapping`: 花卉与地理区域的映射关系 —— 省份与花卉的关联、地球标注渲染
- `season-filter`: 季节筛选功能 —— 按春夏秋冬过滤花卉，动态更新地球视图
- `flower-detail`: 花卉详情展示 —— 点击标注后显示花卉完整信息面板
- `flower-data-pipeline`: 真实花卉数据采集流水线 —— 省市花整理脚本、GBIF API 查询、数据清洗与格式转换

## Impact

- **前端技术**：需引入 Three.js 或 Cesium.js 作为3D地球渲染引擎
- **数据层**：需建立花卉数据集（真实数据，来源：省市花官方资料 + GBIF API）；数据采集脚本需单独运行，产物为 `src/data/flowers.json`
- **UI框架**：季节筛选面板、详情弹窗需与3D场景融合
- **性能**：花卉标注数量较多时需要聚合与 LOD 优化策略
- **资源**：花卉高清图片的加载与缓存策略
